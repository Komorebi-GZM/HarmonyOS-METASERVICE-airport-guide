## 0. 结论先行

一个可编译、可跑、可演示的真元服务，页面骨架：

```
Index（机场总览 · Navigation 宿主）
 ├─ SelectTarget（终点：分类 Tabs + 搜索 + 起点区）
 │    └─ SelectStart（起点：快捷 chips + 全节点检索）
 ├─ Route（逐层路径图：Tabs 按楼层 + 换层提示 + 动效）
 ├─ MetroGuide（地铁换乘引导：方向 → 步骤链 → 站台预览）
 └─ FloorBrowse（楼层浏览：单层示意 + 点节点详情）
```

核心技术：
- **寻路**：Dijkstra（walk 用米权，垂直边权重 电梯30/扶梯40/楼梯25，偏好乘子 `PREF_MULT`）+ **安检必经拆分**（起点终点异侧时拆成 `起→安检→终` 两段）。唯一安检是割点，该拆分严格等价于"不可能绕过安检"。
- **渲染**：Canvas 单层绘制 = **程序化示意图背景**（纸面 + 25m 网格 + walk 边通道带 + 楼体轮廓）+ **拓扑层**（节点/边/双语标签）+ **路径层**（白描边红线 + 0→1 生长动效）。三层共用同一视口变换，天然对齐。
- **数据**：`data/XHA_xinghai_t1.map.json` 为唯一数据源，`tools/gen_model.py` 编译成类型化 `model/AirportMap.ets` 进包（119 节点 / 145 边 / NODE_EN 翻译 / side 陆空侧 / FLOOR_BBOX；**键值字典一律 `Map` 化**——ArkTS 禁用 `Record` 对象字面量）。
- **双语**：运行时文案表 `Loc.ets`（`ZH`/`EN`，key 与 `resources/base|en_US/string.json` 对齐，随时可并轨 `$r`）+ 节点名 `AirportMap.NODE_EN`；`@StorageLink('lang')` 即时切换。

## 2. 页面与导航

采用 `main_pages.json` 只注册首页、二级页全部走 **Navigation + NavDestination 组件分发**（照 StoreDisplay 模式），页面间用 `NavPathStack`。

| 页面 | 组件 | 用途 | 进出 |
|---|---|---|---|
| 首页 | `Index.ets` | 机场总览、楼层速览、主入口（找设施/地铁/双语） | Navigation 宿主 |
| 终点选择 | `SelectTarget.ets` | 分类 Tabs + 搜索 + 结果列表 | 点目标 → push('Route') |
| 起点选择 | `SelectStart.ets` | 快捷起点 chips + 全节点下拉检索 | 选中 → 写 Router.startId → pop |
| 路线 | `Route.ets` | 逐层路径图（Tabs 按路线涉及楼层）+ 换层提示 + 动效 | push 带 {startId, endId} |
| 地铁引导 | `MetroGuide.ets` | 选方向 → 引导链（B1闸机→B2站台）→ 复用逐层图 | choose → push('Route') |
| 楼层浏览 | `FloorBrowse.ets` | 任意一层静态示意 + 点节点详情（bindSheet） | push 带 floor |

- `Index.ets` 的 `Navigation(this.pathStack)` 内挂 `navDestination(PageMap)` 分发全部二级 `NavDestination` 组件（含 SelectStart）；
- 跨页参数走模块级 `Router` 静态类（startId / endId / endName / browseFloor / metroDir），避免 ArkTS `param` 类型坑；
- 楼层内翻页用 **Tabs**（路线楼层顺序），切换有转场。

## 4. 寻路引擎（core/Pathfinder.ets）

### 4.1 数据形态

无向图（数据已去重 A↔B）。邻接表 `Map<string, Map<string, number>>`：`from → {to: weight}`；垂直边类型记在边表里用于偏好加权。

### 4.2 两侧判定（陆侧 / 空侧）

从数据一次性计算：去掉安检节点后，从任一陆侧锚点（如 `xha_p4_doorW`）BFS，可达集 = 陆侧；`gate`/`空侧商业`/`3F 夹层` 等不可达 = 空侧。该分类写进 `AirportMap.ets`（生成时附带 `side: 'land'|'air'`），避免运行期重复。

### 4.3 Dijkstra（最小堆或朴素：119 节点规模，朴素即可）

```
path(start, end, preference):
  w(e) = walk ? e.weight
       : vertical_type_weight(e.type) * preference.get(e.type, 1)
```

偏好档位（`PREF_MULT × 基准权重`，基准 电梯30/扶梯40/楼梯25；walk 边永远用米权不乘）：
| 偏好 | elevator | escalator | stair |
|---|---|---|---|
| 最短距离（默认） | 1.0 → 30 | 1.0 → 40 | 1.0 → 25 |
| 优先电梯 | 0.7 → 21 | 1.6 → 64 | 3.2 → 80 |
| 优先扶梯 | 1.3 → 39 | 0.8 → 32 | 2.2 → 55 |
| 避开楼梯 | 1.0 → 30 | 1.4 → 56 | 6.0 → 150 |

### 4.4 安检必经（核心）

```
if start.side == end.side:
    route = singleDijkstra(start, end)          # 同侧不含折返安检
else:
    route = concat(dijkstra(start, SEC), dijkstra(SEC, end))   # 拼接，SEC 醒目标注
```
- 唯一安检是割点 → 异侧任意路径必经安检 → 拆段结果严格等价、且天然最短；
- 拆段去重：`seq = dijkstra(start,SEC).concat(dijkstra(SEC,end).slice(1))`（第二段去掉重复的安检头）；
- 路径输出 `Route` 数据：`{ nodeIds, totalMeters, legs:[{floor,nodeIds,meters}], transitions:[{fromId,toId,viaType,viaName,fromFloor,toFloor,meters}], viaSecurity }`；`legs` 按楼层连续段分组、`transitions` 为换层边清单；楼层顺序 = 路径实际经过楼层序（可能折返同层→legs 键用 `floor:idx` 保证唯一）。

### 4.5 正确性自测

开发期用 `tools/` 加一段 Python 参照实现（同样的图 + 同样的安检拆分），生成 500 条随机 (起,终) 用例与端侧 Pathfinder 结果比对（`duration`/经过节点序列一致，且异侧必有安检）。脚本化，回归可跑。

## 5. 渲染（ui/FloorCanvas.ets + core/Viewport.ets）

### 5.1 视口（Viewport.ets）

`{ zoom, tx, ty }`：屏幕坐标 = `tx + 图x·zoom`、`ty + 图y·zoom`（数据坐标 px，`pxPerMeter=2`）。`fit(bbox,w,h,pad)` 把全层包围盒适配进画布并居中（带边距，zoom 钳制 0.15~8）；`pinch(cx,cy,factor)` 以触点不动点缩放；`pan(dx,dy)` 平移（带 ±2000 钳制）。背景/拓扑/路径三层共用同一变换 → 天然对齐；**仅楼层切换时重 `fit`**，平移缩放不清零。比例尺 = `meters·PX_PER_METER·zoom`。

### 5.2 示意背景层（程序化绘制，数据驱动）

`FloorCanvas.drawBase` 逐层先画：
1. 纸面底色（`Theme.MAP.surface`）铺满 canvas；
2. **网格**：按 `PX_PER_METER×25m` 一格画浅网格（`Theme.MAP.grid`）；
3. **楼体轮廓**：全层 bbox 外扩 26px 的圆角描边（`roundRect`）；
4. **通道带**：把同层 walk 边画成半透明粗线（`corridor #B6AFA2`、圆角线帽、宽 10）——由数据几何直接生成走廊脉络，无需额外坐标。
- 背景纯几何、与拓扑共用同一视口变换 → **对齐是构造上保证的**；
- 视觉上偏「拓扑示意图」而非写实手绘（观感朴素可后续换 `drawImage` 位图插槽，接缝点在 `drawBase`）。

### 5.3 拓扑层

- 非 walk 边（电梯/扶梯/楼梯）：同层端点才就地推进（跨层边由节点色表达，不跨层画）；
- 节点圆：类型色（`Theme.TYPE_COLOR`），`corridor` 小点 r=3.2、POI（gate/metro/baggage/checkin）r=4、安检 r=6.5 且白描边突出；
- 标签：`nodeName(n, en)` 双语，`zoom > 0.55` 才绘制、走廊/换层设施默认省略名（仅 3 处特例贴标），登机口中文去「登机口」前缀只留位号。

### 5.4 路径层

- 高亮折线：白色描边（11px）+ 主色红线（5px，与安检同色 `#E34948`，强化「必经安检」叙事）+ 起/终点 pin 图标（绿/蓝）；
- `progress 0→1` 控制折线裁剪比例（`cutPolyline` 按累计长度内插），实现路径生长动效；
- 安检必经：`viaSecurity` 层绘制红色小圆 + `安检/SEC` 徽标（仅安检所在层）；楼层标注数量随 `leg.meters` 展示。

### 5.5 动效

- 路径入场：`setInterval(16ms)` 驱动 `progress += 0.02`（≈0.8s 线性），`cutPolyline` 只画前段；
- 页面/楼层切换：Navigation 页转场 + Tabs 楼层切换默认转场；
- 安检必经无独立脉动（路线红线即安检色，卡片静态展示）；「楼层 Tabs 切换才重套视口 fit，平移/缩放不清零」。

## 6. 六个功能点实现要点

### ① 总览首页（Index.ets）
- 头部：机场名（`XHA_META.name`）+ 副标题 + 右上「中 / EN」胶囊开关 → `toggleLang()` 写 `AppStorage('lang')` 即时切换（§6.7）；
- 三大功能卡（`entryCard`）：找登机口·设施 → SelectTarget、地铁换乘 → MetroGuide、楼层漫游 → FloorBrowse；
- 快捷直达 `HOT_DESTINATIONS` 横向 chips（点即从默认起点 4F 西出发门 直达规划）；
- 楼层导览 `ForEach` 六层卡（`floorTile`），点击 → 写 `Router.browseFloor` → FloorBrowse；
- Navigation 宿主挂 `PageMap` 分发全部 5 个二级页。

### ② 终点选择（SelectTarget.ets）
- `Tabs`：全部 / 登机口 / 值机安检 / 出入口 / 行李 / 地铁 / 接驳交通 / 停车地面 / 商业服务 / 换层设施；
- `TextInput`：子串匹配 zh+en 名；结果 `List` 行 = 类型色点 + 中文名 + 安检徽标 + 类型·楼层·楼层名；
- 顶栏含「起点」区（显示当前起点，可点入 SelectStart 换）；点结果 → 写 Router.end* → push `Route`。

### ③ 起点选择（SelectStart.ets，全页）
- `List` 快捷起点 chips：西/北/东出发门、2F 主到达出口、B2 地铁站台·市区/星湖、1F 出租网约、B1 交通中心；
- 「全部节点」检索：`TextInput` 过滤 119 节点，行尾 ✓ 标当前起点；
- 选中 → 写 `Router.startId` → pop 回上一页；会话内下次默认。

### ④ 跨层寻路 + 安检必经（core/Pathfinder）
- §4 实现；结果返回 `Route` 数据；`Route.ets` 在摘要卡下放「安全徽标」卡：异侧显示「途中需通过中央安检大厅」、同侧显示「同侧直达，无需安检」；安检所在层的 FloorCanvas 叠红色小圆 + `安检/SEC` 徽标。

### ⑤ 逐层路径图（Route.ets）
- `Tabs` 按路线经过的楼层顺序（不是固定六层）生成分页，每页 `FloorCanvas` 只画该层路径段；
- 页底换层横幅：如「乘 中庭观光电梯 → 1F / +30m」；
- 顶栏：起`→`终 + 总距离 + 换乘次数；路径动效入场。

### ⑥ 地铁换乘引导（MetroGuide.ets）
- 页内两方向卡片（往市区 / 往星湖度假区，选中高亮描边）；
- 选定后目标固定为 `xha_b2_platA/platB`，从 `Router.startId`（默认 4F 西出发门或已选起点）按 §4 寻路；
- 三步指引卡：`B1 闸机群 → 地铁扶梯 → B2 站台`（`metro_step_*_t/_d` 标题+描述成对）；页底 B2 层 FloorCanvas 预览；复用 §⑤ 逐层图。

### ⑦ 中英双语
- 运行时文案表 `Loc.ets`：`ZH`/`EN` 两个 `Record`，key 与 `resources/base` 和 `en_US/element/string.json` 命名对齐（随时可并轨 `$r`）；切换经 `@StorageLink('lang')` + `AppStorage.setOrCreate('lang')` 即时生效；
- 节点名级：`AirportMap.ets` 内 `NODE_EN`（生成时翻译全量 119 节点）+ `Localization.nodeName(n, en)`；未知回落中文；
- 类型/分类/楼层名：`Localization`（typeLabel/floorName）+ `Loc.floor`；Canvas 标注随 `lang` 重绘。
